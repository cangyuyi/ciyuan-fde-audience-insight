## 修复的关键缺陷

- active／retired 不可变与 OLD/NEW 数据库保护。
- limitations 去重、PII、容量和强制边界优先。
- graph／semaphore／fallback／attempt 总 deadline；uvloop 统一事件循环时钟。
- feedback 真实 run/thread/dataset 关联；422 与 OpenAPI 一致；readiness 失败语义。
- workspace grant 与 URL path 的直接标识符防护。
- 多域路由和 checkpoint 元追问；真实跨域证据覆盖。
- M3完整原声、M2场次／日期、M3-02全部100行标签、M4订单与标签、M5观点等级。

## 保留边界

1. 未调用真实 OpenAI；没有真实模型语义忠实度、成本和延迟结论。
2. 未启动真实 Postgres；实库迁移、事务并发、checkpoint恢复、多副本仍需集成验收。
3. 未运行 Docker/Compose、外部 CI、生产 SSO/TLS、备份恢复和负载测试。
4. 默认 memory＋deterministic mock 只证明本地真实 HTTP 端到端链路。
5. M3总体分母与代表性不可由材料证明；YOUNG一手证据仍为未知，Y1只可小规模可回退验证。
6. 采用耗时为设计目标，不是真实业务采用效果。
